# Contribution Guidelines

Merci de votre intérêt pour contribuer à ce projet ! Voici quelques étapes pour vous guider :

## Comment contribuer ?

1. **Forkez le dépôt** : Cliquez sur le bouton "Fork" en haut à droite de la page GitHub.
2. **Clonez votre fork** :
   ```bash
   git clone https://github.com/votre-utilisateur/Application-de-Gestion-d-un-Club-Sportif.git
   ```
3. **Créez une branche** :
   ```bash
   git checkout -b nom-de-votre-branche
   ```
4. **Effectuez vos modifications**.
5. **Testez vos modifications**.
6. **Soumettez une pull request** :
   - Allez sur votre fork sur GitHub.
   - Cliquez sur "New Pull Request".
   - Ajoutez une description détaillée de vos modifications.

## Règles de contribution

- Respectez les conventions de codage existantes.
- Ajoutez des tests pour toute nouvelle fonctionnalité.
- Documentez vos modifications dans le fichier README.md si nécessaire.
- Assurez-vous que votre code est exempt d'erreurs avant de soumettre une pull request.

## Communication

Si vous avez des questions, ouvrez une issue ou contactez les mainteneurs du projet.

Merci pour votre contribution !
